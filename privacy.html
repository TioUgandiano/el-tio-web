Privacy Policy

Effective September 11, 2026

Claude El Tio is a private automation integration, built and operated by Salvador (contact: peluchorango@gmail.com), that publishes short-form video content to a single TikTok account ("El Tio") on a schedule. This policy explains the limited data the integration handles and how it is used.

01 Data this app accesses

DataSourceWhy
OAuth access & refresh tokens TikTok Login Kit, issued when the account owner authorizes the app Required to call TikTok's Content Posting API on the owner's behalf
Basic account identifiers (open id, display name) TikTok API, returned after authorization Confirms which account a scheduled post is being published to
Video files & captions Prepared directly by the account owner The content that gets uploaded to TikTok

02 What is not collected

This integration does not read TikTok direct messages, does not access other users' accounts or content, does not collect analytics on viewers, and does not use TikTok data for advertising, profiling, or any purpose other than publishing the owner's own videos.

03 How data is stored

Access tokens are stored only within the owner's private automation environment (a self-hosted workflow platform) and are used solely to make authenticated calls to TikTok's API at the moment a scheduled video is published. Tokens are not shared, sold, or exposed to any third party.

04 Retention & deletion

Tokens are retained only for as long as the integration remains active. The account owner can delete all stored data at any time by revoking the app's access in TikTok's account settings, which also invalidates the associated tokens.

05 Owner's rights

Because this integration operates on a single, owner-authorized account, there are no third-party end users whose data is processed. The account owner may request details about, or deletion of, any data this integration holds by writing to the contact address below.
